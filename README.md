# McLane Art of the Possible

Eleven-slide deck. Open `index.html` in a browser for the live version (GIFs play). `mclane-aotp-deck.pdf` is the same deck as still pages for download or email.

Fonts load from the web, so the HTML deck needs a connection the first time it opens.

## Publish on GitHub Pages

1. Create a repository and upload everything in this folder.
2. In the repository settings, turn on GitHub Pages from the main branch, root folder.
3. Share the Pages URL. Visitors land on the deck.

Every file in this folder is used by the deck. Keep them next to `index.html`. Do not rename the images.
